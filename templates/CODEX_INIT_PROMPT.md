# 给桌面 Codex 的初始化提示词

**每个新项目发一次**（在已经进行中的旧会话里发效果最好，因为它熟悉项目现状）。
它会把规矩写进项目 `AGENTS.md`，并吐一段新会话用的交接提示词。

复制下面代码块里的内容：

```
我要告诉你一条新的工作方式，请你记进项目记忆，以后按它配合我干活。本会话快到上下文上限了，所以你还要帮我产出一段新会话用的交接提示词。

一、背景事实（请记住）
- 我装了 WebCodex（~/.local/share/webcodex）。启动方式：双击「应用程序/WebCodex.app」。
- 它让 ChatGPT 网页版（chatgpt.com，必须是「聊天」模式，不是工作/Codex 模式）
  通过 @WebCodex 读写我本机的项目目录。当前开放的就是这个项目。
- 两份额度分开算：你的额度贵、模型强；网页聊天是另一份额度、模型弱一档。
- 两边唯一的交接方式是硬盘上的文件。对话里说的话另一边看不到。
- 网页端禁止读取：node_modules / dist / build / release / .git。

二、分工（严格执行）
- 你负责：澄清需求、写 PRD 和技术方案、拆任务清单、最终验收、诊断疑难 bug。你不批量写代码。
- 网页端负责：照着你的文档一次一条地实现任务。
- 你的方案必须落成文件：docs/PRD.md、docs/DEV.md、AGENTS.md（任务清单）。

三、派工提示词由你写，不用我准备
以后每次你交付完，你自己产出一段「给网页端的派工提示词」，放在代码块里，
我直接复制去网页端粘贴。里面要包含：项目目录、要读哪几份文档、本次只做哪一条任务、
禁止事项、验证命令、动手前先复述理解。
结尾提醒我开工前三件事：WebCodex 服务已启动 / 聊天模式 / @WebCodex。

四、现在做两件事
1. 把下面这段追加进 AGENTS.md（追加到末尾，不要覆盖已有内容）；
   如果项目里有 CLAUDE.md，在末尾补一行「协作方式见 AGENTS.md 的双枪协作章节」。

   ## 双枪协作（桌面 Codex ↔ 网页 ChatGPT）
   - 分工：本客户端负责方案、文档、任务清单、验收；
     网页 ChatGPT（聊天模式 + @WebCodex）负责逐条实现。
   - 前提：本机运行 WebCodex，否则网页端够不着项目。
   - 交接媒介只有文件：docs/PRD.md、docs/DEV.md、AGENTS.md。
   - 任务清单格式：编号｜任务名｜要改的文件｜具体做什么｜怎么验证。一次只派一条。
   - 派工提示词由本客户端产出，用户只负责复制到网页端。

2. 写一段「新会话交接提示词」，放在一个代码块里，我复制去开新会话用。
   不超过 300 字，必须包含四样：
   ① 本项目现在做到哪一步
   ② 待办清单里接下来最该做的两三条
   ③ 双枪协作规矩的浓缩版（分工 / 交接靠文件 / 一次一条 / 派工提示词由你出）
   ④ 新会话里你接手后的第一个动作（先读哪几个文件、先输出什么）
```
