# 验收提示词模板（回到桌面 Codex 用）

```
读一下这次的改动：<改动的文件清单>

站 Reviewer 的角度审：
- 有没有踩 PRD 里「明确不做」的红线
- 有没有违反 DEV.md 里的约定
- 有没有隐藏 bug、边界没覆盖、安全问题

输出问题清单并标严重级别（严重 / 中级 / 轻微）。
严重和中级的你直接改掉，改完说明改了什么、为什么这样改。
最后告诉我 AGENTS.md 里的任务状态要不要更新。
```
