# 验收提示词模板（回到桌面 Codex 用）

## 一句话版（推荐，前提是派工单已经生成）

网页端会把完工报告写回 `docs/DISPATCH-00N.md` 的「## 完工报告」小节。
所以回桌面端只用这一行，它自己读：

```
看 docs/DISPATCH-001.md 这条任务的产出，按 PRD 验收。
```

想让它顺手准备下一轮派工，就多带一句：

```
看 docs/DISPATCH-001.md 的产出，按 PRD 验收。通过后更新 AGENTS.md，并给出下一条任务的派工单和那一行复制的话。
```

## 完整版（要指定特殊角度时用）

```
读一下这次的改动：<改动的文件清单>

站 Reviewer 的角度审：
- 有没有踩 PRD 里「明确不做」的红线
- 有没有违反 DEV.md 里的约定
- 有没有隐藏 bug、边界没覆盖、安全问题

输出问题清单并标严重级别（严重 / 中级 / 轻微）。
严重和中级的你直接改掉，改完说明改了什么、为什么这样改。
最后告诉我 AGENTS.md 里的任务状态要不要更新。
```

# 更新清单

```
根据刚才的结果更新 AGENTS.md：完成的标 ✅，新发现的问题补成新任务放到清单末尾。
然后把下一条任务的派工单写成 docs/DISPATCH-00N.md，并给我那一行可以复制的话。
```
